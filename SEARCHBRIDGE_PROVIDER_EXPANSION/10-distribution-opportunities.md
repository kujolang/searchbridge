## SearchBridge-owned channels

- GitHub provider/capability matrix with fixture-backed badges.
- MCP server/catalog exposing semantic tools, not vendor endpoint tools.
- Kujo Agent Skill and plugin that delegates to the same CLI contract.
- Dispatch/WebOps examples: traffic decline evidence pack; rank/SERP comparison; edge-versus-session traffic; crawl/performance/index inspection.
- CI examples using fixtures/encrypted replay and capability health gates.
- External signed-adapter starter and conformance badge.
- API directories only after a stable public adapter authoring contract exists.

## Guardrails

Do not say a provider endorses SearchBridge, that an integration is listed in a marketplace, or that a partner program will distribute it without first-party confirmation. Do not publish provider logos or raw fixture data without license review. Distribution examples must state which calls can consume paid units and default to fixture/offline mode.

## High-value examples

1. Agency organic-decline evidence: GSC + GA4/Plausible + CrUX + Semrush/DataForSEO + backlinks.
2. Developer launch check: SerpApi SERP snapshot + GSC inspection + PSI/CrUX + Cloudflare edge analytics.
3. Publisher traffic discrepancy: first-party analytics versus Cloudflare request counts versus Similarweb estimates, preserving all three semantic classes.
4. Rank opportunity pack: queries in positions 4–15, first-party impressions/CTR, tracked rank change and conversion evidence; the workflow interprets, SearchBridge only supplies normalized inputs.
