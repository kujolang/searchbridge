# SearchBridge Agent Instructions

SearchBridge fetches and normalizes provider evidence; it does not interpret
SEO performance. Preserve capability-level degradation, fixture-first tests,
read/write separation, bounded rows and request timeouts, and redacted errors.

Never commit or log tokens, service-account files, refresh tokens, IndexNow
keys, provider request headers, or raw credential-bearing URLs. Submission
requires explicit `--act --yes` on every invocation.

Run `bash scripts/validate.sh` before committing.
