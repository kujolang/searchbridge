# SearchBridge 0.4.0 release qualification

Qualification is being refreshed on 2026-09-02 against the SearchBridge 0.4 release-candidate series and Kujo runtime commit `67e880a9688dd5770d4a67311d45aa551e6a6fd6`. The reference host is macOS Darwin 25.3.0, Intel Core i7-9750H, 16 GiB RAM, with `kujo 1.2.3`.

## Verification record

- `bash scripts/validate.sh`: 241 passed, 0 failed; 13 public 0.2.x goldens remained readable; 28 golden envelope and row-schema contracts were represented by generated SDK consumers.
- `npm ci && npm run check` in `sdk/typescript`, `go test ./...` in `sdk/go`, and `cargo test` in `sdk/rust`: passed.
- Built-in and signed external adapters passed the common conformance report. Provider catalog, immutable snapshots, authentication/format/pagination metadata, documentation links, and fixture hashes matched.
- A fresh local clone at the qualified commit passed `scripts/validate.sh` with the pinned runtime and produced a valid two-provider fixture response for `fetch --capability serp.results --provider all` without credentials.
- GitHub Actions passed the `validate` and `sdk-compatibility` workflows for the implementation commit. The `platform-smoke` workflow supplies Linux, macOS, and Windows launcher coverage; its final qualification result is attached to the release commit.

## Performance and output budgets

Five warm fixture launches measured 0.23, 0.23, 0.24, 0.24, and 0.24 seconds (median 0.24 seconds), below the 350 ms ceiling and without regression from the post-fix baseline. A later sample under unrelated host load measured 0.37 seconds median and was rejected as a noisy run under the documented stable-threshold rule.

The 100,000-row expansion benchmark was repeated five times. Median results were 588.612 ms for 100 registry discoveries, 1,087.474 ms for 300 routing resolutions, 1,367.864 ms for bounded CSV parsing (73,106 rows/second), and 108.211 ms for atomic JSONL publication. Streaming retained 1,000 rows, remained atomic, and the agent catalog serialized to 1,164 bytes. `scripts/benchmark.kujo -- --iterations 100` produced 280.460 normalized operations/second with 56,800 output characters.

Measured static output sizes were 5,469 bytes for providers, 4,266 for capabilities, 1,165 for the agent catalog, 866 for help, and 21,104 for the full schema set. All are within the budgets in `09-performance-token-budgets.md`.

## Security and release controls

The adversarial corpus covers endpoint templating, redirects/private destinations, deep and oversized responses, credential placement/redaction, cache fingerprints, retry amplification, paid-call preflight, external-package tampering, unknown keys/versions, and write rejection. Submission still requires `--act --yes` on every invocation. The signed Plausible reference package validates canonical manifest/file coverage without shipping a private key.

Release SBOM and provenance are generated by `scripts/release_artifacts.kujo` and bind the release version, source commit, schemas, SDKs, adapters, integrations, and fixtures.

## External blockers and live evidence

No operator supplied DataForSEO, SerpApi, Cloudflare, or Plausible credentials, and no explicit paid-live authorization was granted. Therefore no live rows or paid quota use are claimed; credential-gated live probes remain opt-in. Semrush live execution and public distribution remain intentionally blocked pending explicit commercial, entitlement, retention, and redistribution review. These are external qualification blockers, not fixture or conformance failures.
